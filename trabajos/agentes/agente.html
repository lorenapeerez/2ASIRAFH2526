📱 Configuración Agente IA Local - Lorena Pérez

Mi Hardware (Intel i5-1035G4 + 12GB RAM)

✅ Perfecto para modelos 7B cuantizados (GPU Iris Plus 4/32 capas)

📥 Paso 1: Descarga LM Studio

lmstudio.ai → Windows → Instalar
Abrir → Discover → Qwen2.5-Coder-7B-Instruct (Q4_K_M)

⚙️ Paso 2: Configurar Servidor (Mi configuración personal)

  1. Developer Tab → Load Model → GPU Offload: 4
  2. ⚙️ Settings → ☑️ Enable CORS + ☑️ Local Network
  3. 🟢 START Server → Puerto 1234 ✓

🖥️ Paso 3: Instalar OpenCode (PowerShell Admin)

winget install OpenJS.NodeJS.LTS
choco install opencode -y
opencode

🔗 Paso 4: Conexión Final

En OpenCode: :provider openai http://127.0.0.1:1234/v1 lm-studio

¡Ya funciona mi IA local!
